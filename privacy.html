日本語

はじめに

Duebell Facility（以下「本アプリ」）は、会社の建物と設備について、法定点検・役所への報告・指摘事項の是正の期限と記録を管理する Windows 用のデスクトップアプリです。本ポリシーは、本アプリにおける情報の取り扱いを説明します。

本アプリは個人情報を一切収集・送信・共有しません。入力したデータはすべて利用者のデバイス（または利用者が指定したフォルダ）内にのみ保存されます。

1. 収集する情報

  • 本アプリは利用者の個人情報を収集しません。
  • 利用者が入力した次のデータは、利用者のデバイス内のデータベースファイル（既定は「ドキュメント」フォルダの DuebellFacility\duebell_assets.db。Duebell IT・Duebell Asset と同じ形式。または利用者が指定した共有フォルダなど）にのみ保存されます：
    • 拠点・建物・設備の情報（管理番号、名称、所在地、用途、延べ面積・階数などの区分、設備の分野・種類・メーカー・型式・容量・出力・冷媒、設置場所、処分と冷媒の引渡しの記録、備考）
    • 点検計画と期限（周期、次の点検期限・報告期限、期限の変更履歴）、点検の記録（実施日、業者、点検者、結果、費用、チェックリストの結果）、報告の記録（提出日、提出先、受付番号、対象期間）
    • 指摘事項と是正（内容、重要度、状態、見積、改修予定日、完了日、費用）、業者（名称、担当者、電話番号、資格）と点検の契約（期間、金額、解約申入れの期限）
    • 利用者が添付したファイル（点検結果報告書・報告書の控え・契約書・見積書・写真など）。データベースと同じ場所の attachments\facility フォルダに写して保存します
    • 点検テンプレート・チェックリスト・期限の日数・管理番号の接頭辞など、利用者が入れた設定
    • 自動・手動のバックアップ（データベースと同じ場所の backup フォルダ。添付ファイルは同じ世代の zip）
  • 次回起動時に同じ状態で開く目的で、表示言語・同意した免責事項の版・列の幅・バックアップの控えの保存先が、本アプリの設定ファイル（duebell_assets.ini。Microsoft Store 版ではアプリ専用の領域）に保存されます。
  • Duebell IT・Duebell Asset との共有：利用者が同じデータベースファイルを選んだ場合、本アプリと Duebell IT・Asset が同じファイルを読み書きします。いずれも利用者のデバイス（または指定したフォルダ）の中だけで行われます。
  • 共有フォルダで使う場合、同時編集を防ぐためのロックファイルに、編集中の PC 名・Windows のユーザー名・時刻が書かれます。これは同じフォルダを使う利用者に「誰が編集中か」を示すためだけに使われます。
  • 業者の担当者名・電話番号など、利用者が入力した取引先の情報も、上記のデータベースにのみ保存されます。
  • これらのファイルが外部へ送信されることはなく、開発者がアクセスすることもできません。

2. 利用目的

上記のデータは、本アプリの機能（台帳の管理、点検・報告の期限の判定と計画の提案、記録と添付ファイルの保管、記録の出力、表示・設定の復元、共有フォルダでのロック）を提供するためだけに使われます。それ以外の目的には使われません。

3. ネットワーク・オンラインサービス

本アプリはインターネットに接続せずに動作します。テレメトリ・利用解析（アナリティクス）・広告・トラッキング・ユーザーアカウントの仕組みを一切含みません。役所への申請や業者とのデータ連携も行いません。

Microsoft Store 版では、試用期間とライセンスの確認、および購入を Windows と Microsoft Store の仕組みを通じて行います。これに伴う情報の取り扱いは Microsoft のプライバシーに関する声明に従います。

4. 第三者への提供

本アプリはデータを収集しないため、いかなるデータも第三者へ販売・提供・開示しません。

5. 書き出し機能について

CSV・印刷用 HTML への書き出しは、利用者が明示的に操作したときにのみ実行され、書き出し先は利用者が指定した場所（印刷用 HTML は一時フォルダ）です。本アプリが自動で送信することはありません。

6. データの保存期間と削除

データは、利用者が削除するまで保存されます。点検・報告・指摘の記録は、保存期間を過ぎても本アプリが自動で削除することはありません。本アプリをアンインストールしても、業務データを失わないようデータベース・添付ファイル・バックアップ（「ドキュメント」フォルダの DuebellFacility）は残ります。不要になったら利用者がフォルダごと削除してください（Duebell IT・Asset と共有している場合は、それらのデータも含まれます）。設定ファイルはアンインストール時に削除されます。

7. セキュリティ

データは利用者のデバイスまたは利用者が指定したフォルダにのみ保存されるため、その安全性は利用者のデバイス・ネットワークのセキュリティ対策に依存します。

8. 子どものプライバシー

本アプリは、子どもを含むいかなる利用者からも情報を収集しません。

9. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。最新版はこのページに掲載します。

10. お問い合わせ

本ポリシーや本アプリに関するお問い合わせ先：G.Works.902@gmail.com

English

Introduction

Duebell Facility ("the App") is a Windows desktop application that keeps a company's buildings and building equipment, the due dates and records of their statutory inspections, the reports to the authorities and the correction of findings. This policy explains how the App handles information.

The App does not collect, transmit, or share any personal data. Everything you enter is stored only on your device (or in a folder you choose).

1. Information we collect

  • The App does not collect any personal information.
  • The data you enter is stored in a database file on your device (by default DuebellFacility\duebell_assets.db in your Documents folder, the same format as Duebell IT's and Duebell Asset's, or another location you choose, such as a shared folder):
    • Sites, buildings and items (number, name, address, use, floor area and other building details, field, kind, maker, model, capacity, output and refrigerant of equipment, location, disposals and refrigerant handovers, notes)
    • Inspection plans and due dates (intervals, next inspection and report dues, history of changes), inspection records (date, vendor, inspector, result, cost, checklist answers) and report records (date filed, recipient, receipt number, period)
    • Findings and corrections (description, severity, status, quote, planned and completion dates, cost), vendors (name, contact, phone, qualifications) and inspection contracts (period, amount, notice deadline)
    • Files you attach (inspection reports, copies of filed reports, contracts, quotes, photos), copied into an attachments\facility folder next to the database
    • Your settings: templates, checklists, due thresholds, numbering prefixes
    • Automatic and manual backups (a backup folder next to the database; attachments in a zip of the same generation)
  • To open the App the way you left it, the display language, the version of the accepted disclaimer, column widths and the second backup folder are stored in the App's settings file (duebell_assets.ini; in the Microsoft Store version, in the App's own storage).
  • Sharing with Duebell IT and Duebell Asset: when you choose the same database file, the App and Duebell IT / Asset read and write that file. This happens only on your device (or in the folder you chose).
  • When the database is in a shared folder, a lock file records the editing PC's name, the Windows user name and the time, to prevent simultaneous editing. It is used only to show other users of the same folder who is editing.
  • Vendor contact details you enter are stored only in the database above.
  • These files never leave your device, and the developer cannot access them.

2. How we use information

The data is used only to provide the App's functionality (keeping the ledger, judging inspection and report due dates and proposing plans, keeping records and attachments, exporting records, restoring the display and settings, and locking a shared database). It is not used for any other purpose.

3. Network and online services

The App works without an internet connection. It contains no telemetry, analytics, advertising, tracking or user accounts. It does not file anything with the authorities and exchanges no data with vendors.

In the Microsoft Store version, the trial period, the licence check and purchases are handled by Windows and the Microsoft Store; the Microsoft Privacy Statement applies.

4. Sharing with third parties

Because the App does not collect data, it does not sell, share or disclose any data to third parties.

5. Export features

Export to CSV and printable HTML runs only when you ask for it, and writes to the location you choose (printable HTML goes to the temporary folder). The App never transmits anything.

6. Retention and deletion

Data is kept until you delete it; the App never deletes inspection, report or finding records automatically. Uninstalling the App leaves the database, attachments and backups (the DuebellFacility folder in Documents) in place so that business data is not lost; delete the folder when you no longer need it (if it is shared with Duebell IT / Asset, it holds their data too). The settings file is removed with the App.

7. Security

Data is stored only on your device or in a folder you choose, so its security depends on the security measures of your device and network.

8. Children's privacy

The App does not collect information from anyone, including children.

9. Changes to this policy

This policy may be updated as needed. The latest version is always published on this page.

10. Contact
